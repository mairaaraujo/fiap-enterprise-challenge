# FIAP Enterprise Challenge

Welcome to the FIAP Enterprise Challenge repository! This project contains comprehensive analysis and solutions developed as part of the FIAP (Faculdade de Informática e Administração Paulista) enterprise challenge program.

## 📋 About

This repository showcases enterprise-level data analysis, modeling, and problem-solving using modern data science and analytics techniques. The project demonstrates practical applications of business intelligence and data-driven decision making.

## 🛠️ Technologies & Languages

- **Jupyter Notebook**: Primary language for interactive analysis and documentation
- Data analysis and visualization
- Business intelligence and reporting

## 📁 Project Structure

The repository contains Jupyter notebooks with detailed analysis, visualizations, and solutions for the enterprise challenge.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab
- Required Python packages (see notebooks for specific imports)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mairaaraujo/fiap-enterprise-challenge.git
cd fiap-enterprise-challenge
```

2. Open Jupyter Notebook:
```bash
jupyter notebook
```

3. Navigate to the notebook files and start exploring!

## 📊 Contents

This project includes:
- Data analysis and exploration
- Business metrics and KPIs
- Data visualizations
- Enterprise solutions and recommendations

## 💡 Usage

Open the Jupyter notebooks in your browser and execute the cells to:
- Explore the data
- Review the analysis
- Understand the insights and recommendations
- Run the models and calculations
